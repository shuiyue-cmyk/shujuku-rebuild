# 执行边界提示词（开发者选项）

## 是什么

开发者页「执行边界提示词」开关。开启后，数据库发出的每一次 AI 请求（填表、剧情推进、Agent、续写、正文优化、改表助手、总结等）都会在开头连续的 system 段之后多一条固定的 system 消息，把模型拉回指令范围内。默认关闭；关闭时请求与原来逐字一致。

针对的是 MiniMax M3.1 Flash 这类「主观能动性过强」的模型：没让做的也顺手做。

## 提示词全文

见 `src/service/ai/scope-guard-prompt.ts` 的 `SCOPE_GUARD_PROMPT_ACU`（唯一来源，本文不复制，免得两处漂移）。要点六条：只做明确要求的事；只依据所给资料、不编造；指令限定范围时只在范围内操作；资料没带来新事实就不改已有内容（一笔带过的小动作、只被提起的人和物不算变化）；拿不准是否必要就不做；严格按格式输出、不续写不代演。

## 为什么放在开头

- 压测里放开头与放末尾效果相当（见下表）。
- 开头是固定前缀，不破坏提示词缓存；Claude / Gemini 协议会把开头连续的 system 收进系统提示字段。
- 放末尾要插在预填充之前、又要避开中部 system 在各后端的兼容差异，徒增复杂度。

## 压测方法

- 模型：OpenCode Go 的 `minimax-m3.1-flash`（免费档当天额度已用完，换成 Go 里的同款）。
- 调用：本机 OpenCode 命令行 2.2.6，自定义无工具代理（系统提示词即扩展的第一段 system），每次独立起服务（并发共用后台服务时会话输出会串台，第一轮因此作废了两条）。
- 消息结构：扩展默认提示词组按「非预填充支持 + strict 合并」口径压平成 system + 一条 user，与开启非预填充时酒馆实际发给上游的结构一致。
- 已知偏差：命令行会在 system 末尾附带约 500 token 的自带环境信息（模型名、日期、工作目录、一个 skill 工具说明），基线组和约束组都带，不影响对比。
- 表结构、填表规则、剧情推进提示词均取自默认模板原文；剧情与表数据为自拟的小样本。
- 评分：脚本自动解析 SQL / JSON 逐条判定「越界」（做了没要求的事）与「漏做」（该做的没做），再人工抽查原文。

## 结果

第一轮并发跑时出现会话串台，整轮作废，下表只计第二到第四轮（共 93 次请求）。

| 场景 | 诱导点 | 不加约束 | 第一版·开头 | 第一版·末尾 | 第二版·开头（采用） |
|---|---|---|---|---|---|
| 「空」楼层（只擦剑、听雨、睡觉） | 默认规则「经历变化时更新」 | 越界 4/4 | 越界 3/4 | 越界 4/4 | 越界 1/6 |
| 用户手动更新说明「只改巴伦年龄」 | 默认规则「每轮必须更新时间」 | 越界 2/7 | 越界 0/7 | 越界 0/7 | 越界 0/4 |
| 正常楼层（买药、听传闻、回旅店） | 检查约束会不会导致漏填 | 漏做 0/3 | — | — | 漏做 0/4，越界 1/4 |
| 只查询的 Agent 请求（数据里留了重复行诱饵） | 顺手「整理」数据 | 越界 0/4 | 越界 0/4 | 越界 0/4 | 越界 0/2 |
| 剧情推进记忆召回 | 编造编码、写正文 | — | — | — | 越界 0/2 |
| 只改一个数字的 JSON / 只替换「不禁」的正文优化 / 只修一个 bug 的代码 | 顺手润色、重排 | 越界 0/9 | 越界 0/9 | 越界 0/9 | — |
| 填表回复漏写 tableEdit 标签（解析器能容忍，只算格式偏差） | — | 6/14 | 2/11 | 1/11 | 0/14 |

第一版剩下的越界都是「空楼层没事找事」：给铁剑描述加上「刚擦拭干净」，给没出场的巴伦补一句「白天曾与林墨说过某番话」。第二版加了第 4 条专门压这一类。

第二版剩下两处，都在规则可宽可严的边界上：空楼层 1 次仍给巴伦补了空话；正常楼层 1 次把只被提起、没有登场的「镇长」建成了新角色。

结论（自动化压测，未在酒馆真机上验证）：MiniMax M3.1 Flash 在要求写得很死的单次任务里其实守规矩；它的越界集中在「规则留了解释空间」的地方——没新信息也要写点什么、用户只要求改一处时仍按默认规则把整轮表都更新一遍。第二版约束能把这两类基本压下去，正常楼层没有因此漏填，填表格式也更稳。

样本量小（每格 2～9 次），只说明趋势，不是精确比例。

## 已知局限

- 约束对所有模型生效；对本来就守规矩的模型基本无影响，但会多出约 300 token 输入。
- 约束第 5 条「拿不准就不做」理论上可能让个别模型在模糊情形下少填；压测的正常楼层没出现，真机上如发现漏填可关掉开关对比。
